# Code of Conduct

Studio adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who participates in the project — in issues, pull requests, discussions, reviews
and any other project space — is expected to follow it.

In short: be welcoming, kind and patient; assume good intent; give and accept constructive feedback gracefully;
and do not harass, insult or demean anyone, or publish anyone's private information without their explicit
permission. Project spaces are for discussing the project.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainer through the contact
options on the repository owner's GitHub profile. Reports are handled confidentially, and the maintainer will
respond as described in the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
